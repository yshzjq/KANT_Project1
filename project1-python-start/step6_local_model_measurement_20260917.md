# STEP 6. 로컬 모델 품질·성능 측정

> 2026-09-17 평가 기록 3개를 정리한 **1차 측정 결과**입니다. 실제 호출 통계와 원본 응답에서 확인되는 내용만 포함했습니다.

## 1. 측정 범위

- 비교 대상: **Qwen3 4B와 EXAONE 3.5 7.8B의 2개 모델 계열**.
- Qwen은 Q4·Q8 양자화 설정을 각각 실행했으므로, 비교하는 실행 설정은 총 3개입니다.
- 각 파일은 **공통 질문 18개를 질문별 1회** 처리한 기록입니다.
- 별도 워밍업 기록과 질문별 2회 반복 기록은 없습니다. 따라서 목표인 **모델당 10문항 × 2회 + 별도 워밍업 1회**를 완료한 결과로 보지는 않습니다.
- STEP 5의 확정된 수치 채점 기준과 채점 결과가 세 파일에 없어 **품질 평균 점수는 제외**하고, 원본 응답과 실제 입력 근거를 비교한 사례를 남겼습니다.

## 2. 실행 조건

| 항목 | Qwen Q4 | Qwen Q8 | EXAONE |

| 최종 답변 모델 태그 | `qwen3:4b-instruct-2507-q4_K_M` | `qwen3:4b-instruct-2507-q8_0` | `exaone3.5:7.8b` |
| 실제 양자화 수준 | Q4_K_M | Q8_0 | Q4_K_M |
| 실제 context_length | 8192 | 8192 | 8192 |
| 답변 직후 CPU/GPU 적재 상태 | 100% GPU | 100% GPU | 100% GPU |

실제 context_length와 적재 상태는 각 실행에서 최종 답변 모델을 호출한 14건 모두 동일하게 기록되었습니다. 여기서 100% GPU는 **모델 적재 상태**이며 GPU 사용률을 뜻하지 않습니다.

공통 생성 설정:

- 검색어 모델: `qwen3:4b-instruct-2507-q4_K_M`
- 검색어 생성: `temperature=0`, `num_predict=256`, `num_ctx=8192`, `stream=false`
- 최종 답변: `temperature=0`, `num_predict=512`, `num_ctx=8192`, `stream=false`

모델 식별값(digest):

- Qwen Q4: `0edcdef34593eac1aa2be9c7d06c432dcf81945adca5eca2f27662c18f168ba0`
- Qwen Q8: `aa7252f68dda4d25dfffa65b3760af6d2c3231a140c0060c78d444686d98a374`

### 입력 비교 조건

세 실행의 질문·유형·기대 결과는 같습니다. 실제 최종 답변 호출 14건을 문항별로 대조한 결과, **선택된 Slack 문맥은 모두 같고, 요청 메시지도 현재 기준 시각을 제외하면 동일**했습니다.

다만 전체 Slack 데이터의 SHA-256은 Qwen Q4와 나머지 두 실행이 다릅니다. 전체 데이터까지 완전히 고정한 실험은 아니며, 위의 동일성은 저장된 최종 답변 입력을 직접 비교한 결과입니다.

## 4. Performance

### 4-1. 전체 평균

| 지표 | Qwen Q4 | Qwen Q8 | EXAONE |
|---|---:|---:|---:|
| 전체 응답 시간, 초 | 1.34 (n=14) | 7.08 (n=14) | 7.54 (n=14) |
| 최종 답변 API 호출 시간, 초 | 0.75 (n=14) | 4.41 (n=14) | 4.74 (n=14) |
| 최종 모델 로딩 시간, 초 | 0.002545 (n=14) | 3.07 (n=14) | 3.08 (n=14) |
| 최종 답변 토큰 생성 속도, tokens/s | 95.82 (n=14) | 70.57 (n=14) | 67.24 (n=14) |
| 최종 모델 VRAM, MiB | 3693.93 (n=14) | 5394.45 (n=14) | 5460.65 (n=14) |
| 검색어 생성 API 호출 시간, 초 | 0.51 (n=18) | 2.56 (n=18) | 2.61 (n=18) |

집계 방법:

- **전체 응답 시간**: 기록된 `elapsed`. 검색어 생성·검색·최종 답변 생성 등 질문 처리 과정을 포함합니다. 첫 토큰 지연(TTFT)으로 해석하지 않습니다.
- **최종 답변 API 호출 시간**: 최종 모델 호출 구간의 시간입니다. 전체 응답 시간의 일부이므로 두 값을 더하지 않습니다.
- **모델 로딩 시간**: 최종 호출의 `response.load_duration / 1,000,000,000`.
- **토큰 생성 속도**: 각 최종 호출의 `eval_count / (eval_duration / 1,000,000,000)`를 구한 뒤 산술평균했습니다.
- **VRAM**: 답변 직후 `client.ps()`에서 해당 최종 모델의 `size_vram`을 MiB로 환산해 기록한 값입니다. 순간 최대치나 PC 전체 GPU 메모리 사용량은 아닙니다.
- `n`은 해당 평균에 사용한 유효 기록 수입니다. 시간 평균은 Markdown에 저장된 값, 로딩 시간과 토큰 속도는 저장된 원본 응답 통계로 확인했습니다.
- 최종 호출 14건씩 모두 로딩·생성 통계가 있었고 `eval_duration > 0`이었습니다. 측정 불가 값을 0으로 채운 항목은 없습니다.

### 4-2. 첫 문항과 이후 문항의 로딩

첫 문항 Q01은 워밍업으로 분리된 실행이 아니므로 위의 전체 평균에도 포함됩니다. Q01 시작 전 최종 모델 상태는 Qwen Q4·EXAONE이 미적재, Qwen Q8이 로드됨으로 기록되어 있습니다.

**Qwen Q4는 검색어 생성과 최종 답변에 같은 모델 태그를 사용합니다.** Q01의 초기 로딩은 검색어 단계에서 발생했고, 이후 최종 답변의 로딩 시간은 매우 짧았습니다.

**Qwen Q8·EXAONE은 검색어 모델과 답변 모델의 태그가 다릅니다.** 첫 문항 이후에도 최종 답변 호출 13건 모두에서 1초 이상의 로딩 시간이 기록되었습니다. 따라서 이후 문항을 모두 “로딩이 끝난 상태의 응답 속도”로 볼 수 없습니다.

현재 응답 시간 차이에는 **모델을 번갈아 호출하는 구성과 반복 로딩**이 함께 반영되어 있습니다. 모델 자체의 생성 성능만으로 이 차이를 설명할 수 없으며, 별도로 통제한 미적재·적재 상태의 성능 수치는 제시하지 않습니다.
