## STEP 1. 문제 정의

> **Slack API를 통해 수집한 교육 데이터를 기반으로 사용자의 한국어 질문에 정확하게 답변할 수 있는 로컬 LLM 기반 Q&A Assistant에 적합한 모델을 선정한다.**

- **어떤 사용자가 사용하는가?**
  - LLM 교육 과정에 참여하는 교육생이 사용한다.
  - 사용자는 교육 일정, 시험, 과제, 운영 안내 등 Slack에 공유된 정보를 질문한다.

- **어떤 종류의 질문에 답해야 하는가?**
  - Slack에 저장된 교육 관련 정보를 바탕으로 질문에 답해야 한다.
  - 단순 정보 검색뿐만 아니라 여러 메시지의 내용을 종합하여 답변해야 할 수 있다.
  - 자료에 없는 내용은 임의로 생성하지 않고, 확인할 수 없다는 사실을 명확하게 안내해야 한다.

- **어떤 성능이 중요한가?**
  - **한국어 이해 및 답변 품질**: 사용자의 질문 의도를 정확하게 이해하고 자연스러운 한국어 답변을 생성해야 한다.
  - **근거 기반 답변**: Slack에서 수집한 데이터를 근거로 답변해야 한다.
  - **Hallucination 억제**: 자료에 존재하지 않는 정보를 임의로 생성하지 않아야 한다.
  - **응답 속도**: 실제 Q&A Assistant로 사용할 수 있을 정도의 응답 속도를 확보해야 한다.

- **모델을 어떤 기준으로 비교하는가?**
  - 동일한 질문과 Prompt를 사용하여 후보 모델의 답변을 비교한다.
  - 답변 품질뿐만 아니라 **응답 시간, 모델 로딩 시간, 생성 속도(tokens/s)** 등의 성능을 함께 측정한다.
  - 답변 품질과 실행 성능 사이의 균형을 고려하여 프로젝트에 적합한 모델을 선정한다.

- **사용 가능한 실행 환경은 어느 정도인가?**
  - 로컬 또는 지정된 서버 환경에서 실행 가능한 모델을 대상으로 한다.
  - GPU 메모리와 실행 자원의 한계를 고려하여 모델 크기와 양자화 여부를 함께 검토한다.
  - 비교 대상인 **Qwen 계열 모델과 EXAONE 계열 모델**이 실제 실행 환경에서 안정적으로 동작하는지 확인한다.
