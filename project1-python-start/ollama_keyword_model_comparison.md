| 비교 모델 | 생성 검색어 평균 | 후처리 검색어 평균 | 선정 시 고려 사항 |
| --- | ---: | ---: | --- |
| **Qwen3 4B** | **4.17** | **4.44** | 4B 규모 후보 중 생성·후처리 검색어 점수가 모두 높아 우선 선정 |
| Gemma 3 4B | 3.94 | 4.39 | Qwen과 후처리 점수 차이가 작지만, Q02·Q09 등에서 질문 밖 검색어가 섞임 |
| Gemma 3 12B | 4.94 | 4.94 | 이번 질문 세트의 품질 점수는 가장 높으며, 품질을 우선할 때의 비교 기준 |

1. **모델 규모와 검색어 품질을 함께 고려했다.**
   - 이번 선정에서는 4B 규모의 후보를 우선 고려하고, 그중 생성·후처리 검색어 점수가 높은 Qwen3 4B를 선택했다.
2. **후처리와 결합했을 때 핵심 검색어를 보완할 수 있었다.**
   - Q01은 분리된 채널명이 후처리에서 `질문잡담방`으로 보완되었다.
   - Q09·Q10은 개발 도구의 이름을 추출했으며, Q18은 `시험`, `날짜`, `범위`를 정확히 추출했다.
3. **남은 약점도 확인했다.**
   - Q03의 과도한 확장과 Q14의 불필요한 표현·중복은 개선 대상이다.
   - Gemma 3 4B와의 후처리 평균 차이는 약 0.06점으로 작으므로, 이 차이만으로 일관된 품질 우위를 단정하지 않는다.

### 6-3. 결정 요약

**검색어 품질과 4B 규모를 함께 고려하여, 본 프로젝트의 키워드 추출 모델은 Qwen3 4B로 결정한다.**

키워드 추출 시간과 실제 VRAM 사용량은 아직 비교하지 않았으므로 성능·비용 우위는 추가 검토가 필요하다. 또한 Q14처럼 동일한 후처리 검색어에 다른 점수가 부여된 항목은 채점 기준을 정리해야 한다.
