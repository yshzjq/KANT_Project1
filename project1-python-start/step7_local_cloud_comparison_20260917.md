# STEP 7. 로컬 LLM과 Cloud API 비교

> 2026-09-17 Cloud 평가 기록 1개와 STEP 6의 로컬 기록 3개를 비교한 **1차 비교 결과**입니다. 실측값·원본 응답을 정리하고, 공식 단가로 계산한 예상 API 비용을 별도로 표시했습니다.

## 1. 비교 범위

- Cloud 답변 모델: `gpt-5.6-luna`
- 로컬 답변 모델: Qwen3 4B(Q4·Q8), EXAONE 3.5 7.8B(Q4)
- 모든 실행의 검색어 모델: `qwen3:4b-instruct-2507-q4_K_M`
- 각 실행은 같은 질문 **18개를 문항별 1회** 처리했습니다. 이 중 실제 답변 모델을 호출한 **공통 14문항 전체**를 비교했습니다.
- Q06·Q13·Q14·Q18은 날짜 조건에 맞는 근거가 없어 프로그램이 안내문을 반환했습니다. 모델 품질·성능 평균에서 제외했습니다.

STEP 7에서 요구한 **사전 확정 공통 5문항**을 식별할 근거가 없으므로 임의로 5개를 골라 본 실험으로 표시하지 않았습니다. 로컬 기록도 문항별 1회이므로, 요구한 “로컬 2회·Cloud 1회” 반복 설계를 완료한 비교는 아닙니다.

Qwen Q4·Q8은 같은 모델의 양자화 비교입니다. 서로 다른 로컬 모델 계열은 Qwen과 EXAONE의 2개입니다.

## 2. 입력과 실행 조건

### 입력 비교

- 질문과 기대 결과는 네 실행에서 같습니다.
- 실제 호출한 14문항의 **선택된 Slack 문맥은 모두 동일**했습니다.
- 최종 요청 메시지는 **현재 기준 시각을 제외하면 동일**했습니다.
- 검색 대상 전체는 Cloud 524개, 로컬 512개 메시지로 다릅니다. 전체 데이터가 고정된 실험은 아니지만, 위 동일성은 저장된 실제 최종 입력을 직접 대조한 결과입니다.

### Cloud 요청 설정

| 항목 | 기록된 값 |
|---|---|
| 요청·반환 모델 태그 | `gpt-5.6-luna` |
| API | OpenAI Responses API |
| reasoning.effort | `none` |
| max_output_tokens | 512 |
| temperature | 요청에서 미지정 |
| stream / store | `false` / `false` |
| tools / tool_choice | `[]` / `none` |
| timeout / max_retries | 180초 / 0 |

Cloud는 temperature를 지정하지 않았고, 로컬은 `temperature=0`으로 요청했습니다. **생성 설정까지 완전히 동일한 비교는 아닙니다.** 출력 한도도 로컬 `num_predict=512`와 Cloud `max_output_tokens=512`로 각각 설정했으며, 모델 간 토큰화 방식이 같다고 가정하지 않습니다.

검색어 생성은 모두 로컬 Qwen에 `temperature=0`, `num_predict=256`, `num_ctx=8192`로 요청했습니다. Cloud 실행에 재사용한 문맥 선택 기준 8192는 Cloud 서버의 실제 context_length가 아닙니다.

## 3. 호출 성공과 응답 시간

### 3-1. 공통 14문항 비교

| 지표 | Qwen Q4 | Qwen Q8 | EXAONE | Cloud Luna |
|---|---:|---:|---:|---:|
| 최종 답변 호출 성공 / 시도 | 14 / 14 | 14 / 14 | 14 / 14 | 14 / 14 |
| 최종 답변 API 실패 | 0 | 0 | 0 | 0 |
| 전체 응답 시간 평균, 초 | 1.34 (n=14) | 7.08 (n=14) | 7.54 (n=14) | **2.35 (n=14)** |
| 최종 답변 API 호출 시간 평균, 초 | 0.75 (n=14) | 4.41 (n=14) | 4.74 (n=14) | **1.78 (n=14)** |
| 검색어 생성 API 호출 시간 평균, 초 | 0.51 (n=18) | 2.56 (n=18) | 2.61 (n=18) | 0.49 (n=18) |

검색어 생성은 각 실행에서 18 / 18건 성공했습니다. 두 단계 합계는 각각 **32 / 32건 성공**이며, Cloud API 호출 자체는 14건입니다. Cloud 응답 14건 모두 반환 상태가 `completed`이고 오류·미완료 사유가 없었습니다. 정상 반환이 내용의 정확성을 뜻하지는 않습니다.

평균은 각 원본 파일의 집계값을 사용했습니다. 개별 시간은 소수점 두 자리로 저장되어 있어, 아래 개별 값을 다시 평균내면 원본 집계와 0.01초 정도 차이가 날 수 있습니다.

### 3-2. 응답 시간 해석

- **전체 응답 시간**은 검색어 생성·검색·진단 수집·이름 조회·최종 답변을 포함합니다. 최초 Slack 동기화, show·ps 조회, 보고서 저장은 제외됩니다.
- **최종 답변 API 호출 시간**은 전체 응답 시간에 포함된 일부입니다. Cloud 호출에는 네트워크와 서버 처리 시간이 포함되며, 두 시간을 따로 측정하지 않았습니다.
- Cloud의 첫 문항 Q01은 전체 6.07초였고, 로컬 검색어 모델 로딩 2.17초가 포함되었습니다. 이를 Cloud 서버의 초기 로딩 시간으로 해석할 수 없습니다.
- Qwen Q4는 검색어와 답변에 같은 모델 태그를 사용합니다. Qwen Q8·EXAONE은 검색어 모델과 다른 모델을 번갈아 호출하며 최종 모델의 반복 로딩이 기록됐습니다. 전체 시간 차이에는 이 실행 구성의 차이가 반영됩니다.
- 첫 토큰 지연(TTFT)은 측정하지 않았습니다. Cloud의 로딩 시간·순수 생성 tokens/s·서버 VRAM은 이 기록으로 산출할 수 없어 수치 비교에서 제외했습니다.

**이번 실행에서는 Qwen Q4 → Cloud Luna → Qwen Q8 → EXAONE 순으로 평균 전체 응답 시간이 짧았습니다.** 이 순서는 현재 구성의 관측 결과이며, 모델 고유의 속도 순위로 일반화하지 않습니다.

### 예상 API 비용

**Cloud 답변 14회 합계는 $0.00557015, 호출당 평균은 약 $0.00039787 (n=14)**입니다. 원본 `usage`에 공식 공개 단가를 적용한 예상치이며, 실제 청구 내역을 조회한 금액은 아닙니다.

요금 확인일은 **2026-09-17**입니다. 반환된 `service_tier`는 14건 모두 `default`이고, 호출별 입력은 최대 2,075토큰이므로 Standard의 짧은 문맥 요금을 적용했습니다. `gpt-5.6-luna`의 100만 토큰당 단가는 일반 입력 $0.20, 캐시 읽기 $0.02, 캐시 쓰기 $0.25, 출력 $1.20입니다. [OpenAI 공식 API 요금표](https://developers.openai.com/api/docs/pricing)

입력 20,579개 중 `cache_write_tokens`는 **16,895개**, `cached_tokens`는 **0개**입니다. 캐시 쓰기 토큰은 전체 입력에 포함되므로 일반 입력에서 빼고 별도 단가를 적용했습니다. 일반 입력은 `20,579 − 16,895 − 0 = 3,684개`입니다. [OpenAI 공식 캐시 비용 계산 방법](https://developers.openai.com/api/docs/guides/prompt-caching#calculate-input-cost)

| 과금 항목 | 토큰 수 | 단가, USD / 100만 토큰 | 예상 비용, USD |
|---|---:|---:|---:|
| 일반 입력 | 3,684 | $0.20 | $0.00073680 |
| 캐시 쓰기 입력 | 16,895 | $0.25 | $0.00422375 |
| 캐시 읽기 입력 | 0 | $0.02 | $0.00000000 |
| 출력 | 508 | $1.20 | $0.00060960 |
| **합계** | **21,087** | — | **$0.00557015** |

계산식:

```text
예상 비용(USD)
= (3,684 × 0.20 + 16,895 × 0.25 + 0 × 0.02 + 508 × 1.20) / 1,000,000
= 0.00557015

호출당 평균(USD)
= 0.00557015 / 14
≈ 0.00039787
```

계산 범위는 이 파일의 **실제 Cloud 호출 14건**입니다. Q06·Q13·Q14·Q18은 Cloud를 호출하지 않았으며, 검색어 생성 18건은 로컬 Ollama 호출입니다. 로컬 장비·전력 비용, 세금·환전 수수료, 계정별 계약 단가·할인·크레딧은 반영하지 않았습니다.

실제 청구 금액은 **미확인**입니다. 원본의 `billing.payer=developer`는 청구 주체만 나타냅니다. 위 예상 비용과 [OpenAI API 사용량 화면](https://platform.openai.com/usage)의 실제 사용·비용 내역은 구분합니다.

수치 채점 기준과 채점표가 없어 품질 평균 점수·정답률은 만들지 않았습니다. 아래는 같은 입력을 사용한 대표 사례이며, 전체 모델 순위를 뜻하지 않습니다.

### 5-2. Cloud에서도 남은 정보 누락

**Q07 — 수업을 듣다가 궁금한 점이 생기면 어디에 질문하면 되나요?**

Cloud 원본 응답:

> 학습 중 궁금한 내용은 질문잡담방에 자유롭게 올리면 됩니다.

질문 장소는 맞게 안내했지만, 실제 입력에 있는 **담당자를 태그하는 방법**은 빠졌습니다. 요청 지침에도 질문에 필요한 태그 방법을 보존하라고 되어 있어, 필요한 정보의 일부가 누락된 사례입니다.

같은 질문에서 Qwen Q4도 장소만 안내했습니다. Qwen Q8은 공지 작성자를 명시해 태그 방법을 안내했고, EXAONE은 “저를 태그”라고 답해 공지 작성자와 Assistant의 역할을 혼동했습니다.

Q06·Q13·Q14·Q18의 안내는 프로그램이 생성했으므로, 이를 Cloud 모델이 현재·과거를 올바르게 구분한 성공 사례로 채점하지 않았습니다.

## 6. 운영 조건: 기록에서 확인되는 차이

이 절은 성능 점수가 아닌 **실제 구성에 대한 설명**입니다.

| 기준 | 이번 로컬 구성 | 이번 Cloud 구성 |
|---|---|---|
| 모델 호출 경로 | 검색어·답변 모두 PC의 Ollama | 검색어는 PC의 Ollama, 답변은 외부 Responses API |
| 답변에 쓰는 Slack 문맥 | 로컬 Ollama에 전달 | 선택된 Slack 문맥을 외부 API에 전달 |
| PC에서 실행하는 모델 | 검색어·답변 모델 | 검색어용 Qwen 모델 |
| 연결·운영에 필요한 구성 | Ollama 서버와 로컬 모델 | Ollama 서버·검색어 모델과 외부 API 연결 |

Cloud 실행에서도 검색어 모델의 질문 직후 VRAM은 평균 **3693.93 MiB (n=18)**로 기록됐습니다. 이는 로컬 Qwen의 관측값이며 Cloud 서버의 VRAM이나 PC 전체 최대 사용량이 아닙니다.

저장된 Cloud 요청 문맥에는 Slack 작성자 이름과 사용자 ID가 포함되어 있습니다. **공개·가상 데이터만 사용했다는 조건은 이 파일로 확인되지 않으므로 보안 요건을 충족했다고 결론내리지 않았습니다.** `store=false`는 기록된 요청 설정으로만 다뤘습니다.

장비·전력·관리 비용, 실제 API 청구 금액, 모델 커스터마이징 효과는 측정 자료가 없어 비교에서 제외했습니다.

## 7. 정리

- Cloud는 **최종 API 호출 14 / 14건 성공**, 전체 응답 평균 **2.35초 (n=14)**였습니다.
- 같은 입력에서 Qwen Q4가 놓친 학습 안내를 반영한 사례가 있었지만, Cloud에도 태그 방법 누락이 있어 품질 우위를 전체 문항으로 일반화하지 않았습니다.
